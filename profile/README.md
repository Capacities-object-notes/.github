# Capacities — Object‑Oriented Notes for Structured Knowledge and Networked Thinking

## About Capacities

Capacities provides object‑oriented notes for structured knowledge, networked thinking, and personal databases for knowledge workers, creators, and project managers. Capacities combines objects, tags, and backlinks. Capacities supports semantic properties, relations, collections, and dashboards. Capacities integrates media embeds, daily notes, and graph view. Capacities enables users to model real‑world entities, link them meaningfully, and query across properties. Capacities is trusted by content strategists, product managers, Zettelkasten practitioners, and lifelong learners worldwide.

## Deep Dive — Object‑Oriented Note Features
Object type definitions: person, project, book, idea, custom
Properties per object: text, number, date, URL, select, multi‑select
Relations linking objects by type (person → writes → book)
Collections grouping objects by property or tag
Backlinks and graph view showing how objects interconnect
